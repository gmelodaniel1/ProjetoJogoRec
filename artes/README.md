# Ativos Visuais de Produção (artes/)

Este diretório contém exclusivamente os ativos visuais finais e otimizados que são carregados pelo jogo no navegador:

- **`cenarios/`**: Fotografias históricas tratadas no pipeline documental noir (WebP / 800×450 px / filtro de jornal).
- **`personagens/`**: Ilustrações e recortes de personagens para exibição nos diálogos (PNG transparente ou WebP / plano médio).
- **`retratos/`**: Retratos 3x4 de prontuário policial do DOPS (WebP / 90×120 px / fichamento antropométrico).

Materiais brutos de pesquisa, PDFs pesados e scans de alta resolução ficam guardados em `acervo-historico/`.
